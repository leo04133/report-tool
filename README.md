# 報表自動整理工具

> ⚠️ **本專案為示範作品，範例資料（門市、品項、金額）皆為虛構。**

把多家門市「格式不一」的銷售報表，一鍵合併成一份整理好的 Excel。

## 解決什麼問題

各分店交來的報表常常欄位名稱不同、日期格式不同、數字夾雜千分位文字、還有空白列和重複列。
手動複製貼上又慢又容易出錯，這個工具會自動處理：

- 讀取資料夾內所有 `.xlsx` / `.xls` / `.csv`（自動略過 Excel 的 `~$` 暫存檔）
- 欄位名稱自動對應（例如「日期 / 銷售日期 / date」都視為日期）
- 統一日期格式、清除千分位與前後空白、刪除空白列與重複列
- 從檔名取得門市名稱（`台北店_2026-10.xlsx` → 台北店）
- 無法辨識的資料不會默默消失，而是列在「異常資料」並註明原因

## 輸出內容（整理結果.xlsx）

| 工作表 | 內容 |
|---|---|
| 明細 | 清理後的所有交易，含金額 |
| 門市彙總 | 各門市筆數、數量、營收與占比 |
| 品項彙總 | 品項 × 門市營收交叉表 |
| 每日營收 | 每日 × 門市營收 |
| 異常資料 | 被排除的資料列與原因 |

## 使用方式

```bash
pip install -r requirements.txt

# 使用範例資料
python merge_reports.py

# 使用自己的資料夾、指定輸出檔名
python merge_reports.py 我的報表資料夾 -o 十月合併.xlsx
```

範例資料位於 `sample_data/`，可用 `python make_sample_data.py` 重新產生。

## 範例資料說明

| 檔案 | 刻意設計的問題 |
|---|---|
| 台北店_2026-10.xlsx | 標準格式（對照組） |
| 台中店_2026-10.xlsx | 欄位名稱不同、數字為含千分位的文字、空白列、重複列、「兩杯」這種非數字數量 |
| 高雄店_2026-10.csv | CSV、英文欄位、月/日/年 日期格式 |
